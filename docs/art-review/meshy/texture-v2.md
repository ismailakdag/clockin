# Reference color refinement

Date: 2026-09-18

The first texture looked pale compared with `robot-reference-v1.png`. Unlit viewing showed that the base color itself was muted; the lit viewer also added cloudy reflections on the face.

A second texture was submitted on the existing source geometry, preserving the first texture for comparison. Settings: Meshy 7 Flagship, text-guided texture, 2K, PBR maps enabled. Cost: 10 credits. Generation completed. Visual inspection rejected this variant: it changed the antenna ball, boot soles, face expression and panel colors instead of only strengthening the reference palette. The original texture remains the selected working version. No texture-editor changes were saved. Export of the original GLB is still unverified; precise base-color and roughness corrections should use the original exported asset rather than further unconstrained texture regeneration.
