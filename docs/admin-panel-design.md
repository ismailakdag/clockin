# Clockin service panel

Private, mobile-first Turkish monitoring screen. Reuse Clockin's porcelain
`#f5f6f8`, ink `#20242b`, secondary `#626873`, orange `#f78a18`, navy `#172237`
and a restrained healthy-state green `#237256`. Native system sans for familiar
iPhone readability; tabular numerals for the live count.

Layout: compact Clockin header and logout, one large active-registration count
inside a timer-like circular outline, service heartbeat alongside it on desktop
and below on mobile, followed by one plain definition list for the last run.
Left-aligned explanatory copy distinguishes registration count from people and
APNs acceptance from delivery. No invented history graph or user identity list.

Review: a number is the primary requested information here, so it earns the
visual emphasis. Avoid a generic dashboard card grid and decorative charts.
Use the circular timer shape as the one Clockin-specific visual element.
Zero, stale data, failed requests and unauthenticated states have explicit copy.
